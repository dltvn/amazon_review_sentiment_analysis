The Problem

Star Ratings Are Coarse

A user who writes "This software is decent but has frustrating bugs" and one who writes "Average product, nothing special" both rate 3 stars. The text carries richer sentiment information that the integer rating collapses.

Our Hypothesis

By extracting sentiment from review text and blending it with the raw star rating, we can produce continuous-valued enhanced ratings that better reflect reviewer intent — and improve downstream recommendation accuracy.

Two-Phase Approach

  • Phase 2: Train and evaluate 6 sentiment classifiers (4 ML + 2 lexicon-based)
  • Phase 2.5: Use the best sentiment signals to enhance ratings for an SVD-based recommender, evaluated via 5-fold CV

Why These Changes?

The unstaged changes represent a complete new feature: a sentiment-enhanced recommender system. The existing Phase 2 sentiment classifiers (LR, SVM, LightGBM, MLP, VADER, TextBlob) provided the foundation. The new work feeds their predictions into an SVD collaborative filtering model to test whether sentiment-aware rating adjustments improve recommendation accuracy. The regenerated plots reflect retuned model parameters from the most recent commit (42492b5).

Per-Class F1 Score Analysis

The Neutral Class Problem

All models achieve 0.83–0.90 F1 on positives and 0.35–0.68 F1 on negatives, but neutral detection is universally weak (0.02–0.36 F1). This reflects the inherent ambiguity of 3-star reviews and the class imbalance (only 13% of data is neutral).

ML Models — Detailed Comparison

ML vs Lexicon gap: ML models average ~0.76 F1 vs lexicon models at ~0.67 F1, a ~13% improvement. The supervised models benefit from learning domain-specific patterns in the Amazon Software review corpus that generic lexicons miss.

Why a Recommender System?

Connecting Sentiment to Recommendations

Phase 2 proved we can classify sentiment effectively. But so what? The real-world application is improving product recommendations. If a user gives 4 stars but writes a negative review, the raw rating misleads the recommender. Sentiment-enhanced ratings capture this discrepancy.

Rating Enhancement Formulas

Linear Blend:

enhanced = 0.7 * rating + 0.3 * sentiment_scaled

Additive Adjustment:

enhanced = clamp(rating + 0.5 * signal, 1, 5)

Sentiment Signals Used

VADER — Continuous compound score [-1, +1]. Captures intensity ("good" vs "GREAT!!!")

SVM — 3-class prediction mapped to {1, 3, 5}. Domain-specific but discrete.

2 signals × 2 formulas = 4 enhanced variants + 1 baseline

Recommender Architecture

Recommender MAE Comparison

MAE rankings mirror RMSE exactly, confirming the finding is robust across error metrics. VADER + Linear Blend achieves 0.6550 MAE vs baseline 0.7844 MAE — a 16.5% improvement.

Formula Comparison: Blend vs Additive

Linear Blend wins for both signals. The blend creates a genuinely new rating scale by mixing two independent signals (70% rating + 30% sentiment). The additive approach makes smaller perturbations that barely shift the distribution, limiting its corrective power.

Signal Comparison: VADER vs ML (SVM)

Why VADER Beats SVM Here

  • Continuous signal: VADER compound [-1, +1] captures intensity gradients; SVM collapses to just 3 values
  • Independent information: VADER's lexicon-based scoring is independent of star ratings; SVM was trained on labels derived from those same ratings, creating circular dependency
  • Granularity: "good" vs "excellent" vs "EXCELLENT!!!" all map to different VADER scores, but SVM groups them all as "positive"

Rating Distributions: Raw vs Enhanced

Linear Blend creates a smooth, continuous distribution that breaks the discrete 1-5 clustering. Additive preserves the original shape with minor shifts. The smoother distribution gives SVD more signal to differentiate similar users and items.

Recommender Enhancement

-16.3%
RMSE improvement over baseline
  • VADER + Linear Blend is the best enhancement
  • Continuous sentiment signals beat discrete ones
  • Blend formula consistently outperforms additive
  • ML (SVM) + Additive slightly worsened performance

The Paradox

SVM is the best sentiment classifier (0.78 F1), but VADER is the best recommender signal (0.6963 RMSE). Classification accuracy and recommender utility are different objectives — continuous scores add more new information to the rating matrix than discrete class labels, even if the classification accuracy is lower.

Future Work & Limitations

Limitations

  • ~99% sparse user-item matrix (12,805 reviews / 1,826 users / 802 items)
  • Single domain (Amazon Software)
  • No top-N ranking evaluation (Precision@k, Recall@k)
  • Fixed hyperparameters (alpha=0.7, beta=0.5)
  • ~595 duplicate (user, item) pairs dropped by Cornac

Next Steps

  • Grid search over alpha/beta per sentiment signal
  • Add transformer-based sentiment (BERT, RoBERTa)
  • Top-N ranking evaluation metrics
  • Test on other product categories
  • Hybrid content + collaborative filtering
  • Explore multi-aspect sentiment (not just overall polarity)
